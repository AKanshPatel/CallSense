# 📞 CallSense – Intelligent Call Memory & Categorization

---

## 🧠 Problem Statement

In today's hyper-connected world, individuals receive **dozens of calls daily** — from friends, family, clients, and unknown numbers. 

Over time, it's difficult to remember:
- Who said what?
- What was the context of a call?
- Were there any action items?
- What was the emotional tone of the discussion?

There’s a need for a **personal intelligent assistant** that can **listen, transcribe, summarize, tag, and help recall** every important detail from phone conversations.

---

## 🚀 MVP Features

### ✅ Core Capabilities
- **Call Categorization**  
  Automatically classify calls into categories like Business, Personal, Support, etc.

- **Tag Extraction**  
  Extract key entities and metadata:
  - Topics discussed
  - People mentioned
  - Emotions conveyed
  - Action items (if any)
